# Photos

Drop your photos in this folder — the site picks them up automatically:

- **`hero.jpg`** — the big photo behind your names at the top of the site.
  Landscape orientation, at least 1920px wide recommended.
- **`gallery-1.jpg`, `gallery-2.jpg`, `gallery-3.jpg`, ...** — the photo gallery.
  Number them sequentially with no gaps (the site stops at the first missing
  number). JPG format, square-ish crops look best.

After adding photos, commit and push:

```
git add images && git commit -m "Add photos" && git push
```
